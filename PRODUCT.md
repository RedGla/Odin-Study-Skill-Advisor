## Product Purpose
Odin is an authenticated AI advisor console with saved and temporary conversations, account settings, and an administrator operations dashboard.
## Users
Signed-in users ask the advisor questions. Administrators manage account access, application rules, usage, and operational events. Audience specialization is not confirmed.
## Capabilities and Constraints
Preserve existing authentication, Google linking, verification, password recovery, session security, chat APIs, account controls, quotas, sorting, and theme preference. Existing uncommitted work must be preserved. React, TypeScript, Vite and Tailwind are already installed; add no dependencies for the redesign.
## Brand commitments
User approved a quiet professional workspace, warm off-white surfaces, dark ink typography, compact navigation, and restrained red accents. Replace the Odin logo and make all routes cohesive.
## Operating Context
User requests a bounded implementation to conserve a limited five-hour usage allowance.
